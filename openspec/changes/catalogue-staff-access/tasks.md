Added while building: `CatalogAccessListener` refuses, before the write, a change to a catalogue's `staffAccess` by anyone but an administrator (a write without a session is the system's own). Without it any signed-in user could edit a catalogue and widen its access, because the catalog schema itself has no update rule. The guard also refuses a non-administrator's change to a catalogue's `schemas` or `filters`, and creating or deleting a catalogue, when the old or new schemas include one a restricted catalogue covers (every covering catalogue feeds the rules). Verify: `tests/Unit/Listener/CatalogAccessListenerTest.php`.
